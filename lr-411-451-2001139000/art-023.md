# Art. 23 Promotionsdurchschnitt, Minuspunkte

1) Der Promotionsdurchschnitt ist der Durchschnitt der Noten sämtlicher Promotionsfächer in der betreffenden Schulstufe. Der Promotionsdurchschnitt wird jeweils auf eine Dezimalstelle gerundet. 5 Hundertstel und mehr werden aufgerundet.

2) Minuspunkte errechnen sich aus der Differenz zwischen der Note 4 und einer allenfalls darunter liegenden Note in einem Promotionsfach. Eine Differenz von einer Note entspricht einem ganzen Minuspunkt; eine Differenz von einer halben Note gilt als halber Minuspunkt. Eine Doppelzählung von Minuspunkten ist unzulässig.
