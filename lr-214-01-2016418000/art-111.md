# Art. 111 Entkräftung von Pfandtiteln

1) Ein Pfandtitel wird entkräftet, indem er mit einem Löschungsvermerk versehen und zerschnitten, perforiert oder diagonal durchgestrichen wird. Der Löschungsvermerk wird datiert und vom Amt für Justiz unterschrieben.

2) Wird das Grundpfandrecht im Grundbuch gelöscht, so wird der entkräftete Titel dem Grundeigentümer auf Verlangen ausgehändigt; andernfalls wird der Pfandtitel vernichtet.
