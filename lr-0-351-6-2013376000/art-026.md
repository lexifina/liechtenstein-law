# Art. 26 Beendigung des Abkommens

1) Dieses Abkommen kann von jeder Partei unter Einhaltung einer Kündigungsfrist von drei Monaten beendet werden.

2) Im Falle einer Beendigung einigen sich die Parteien entsprechend den Bedingungen dieses Abkommens über die weitere Verwendung und Speicherung der von ihnen bereits übermittelten Informationen. Kann keine Einigung erzielt werden, so haben beide Parteien das Recht, die Vernichtung der übermittelten Informationen zu verlangen.
