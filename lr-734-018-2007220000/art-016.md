# Art. 16 Temporäre Bewilligung

1) Scheidet die fachkundige Person (Art. 14) aus dem Betrieb aus, so muss eine neue fachkundige Person beschäftigt werden.

2) Kann der Betrieb vorübergehend keine fachkundige Person beschäftigen, so kann der Netzbetreiber auf Antrag eine temporäre allgemeine Installationsbewilligung erteilen. Diese wird erteilt, wenn der Betrieb einen Elektroprojektleiter Installation und Sicherheit beschäftigt.

3) Die temporäre Installationsbewilligung wird für maximal sechs Monate erteilt. Sie kann auf begründeten Antrag hin von der Regierung um höchstens weitere sechs Monate verlängert werden.
